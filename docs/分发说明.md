# 分发说明（发给别人安装用）

> 结论：**可以分发**。已经做成标准安装包，装完出现在「设置 → 应用」里，能正常卸载。
> 但发出去之前，有三件事必须你自己决定，见下面第 2 节。

---

## 1. 产物在哪

| 文件 | 用途 |
|---|---|
| `dist\InstaTranslate-x.y.z-setup.exe` | **发给别人的安装包**（约 160 KB，内含所有文件） |
| `dist\InstaTranslate\` | 免安装绿色版（整个文件夹拷走即可用） |

安装行为：

- 装到 `%LOCALAPPDATA%\Programs\InstaTranslate`，**不需要管理员权限**
- 开始菜单 → 即时译；桌面快捷方式（可选）
- 「设置 → 应用 → 即时译」里可卸载
- 卸载**不删**个人数据（`%APPDATA%\InstaTranslate` 里的设置/历史/生词本）

版本升级：直接运行新版安装包覆盖即可，配置和历史都保留。

---

## 2. 发出去之前必须决定的三件事

### 2.1 要不要买代码签名证书（最影响观感）

现在的安装包**没有数字签名**，别人第一次运行时 Windows 会弹：

> Windows 已保护你的电脑 —— 已阻止无法识别的应用

右上角「更多信息 → 仍要运行」可以继续。**这不是病毒提示，是"未知发布者"**。

| 方案 | 成本 | 效果 |
|---|---|---|
| 不签名 | 0 | 每个人都要点一次"仍要运行"，部分单位会被 IT 拦 |
| OV 代码签名证书 | 约 ¥1000–2000/年 | 装完第一次可能还提示，累积信誉后消失 |
| EV 代码签名证书 | 约 ¥3000–5000/年 + 硬件 UKey | 立刻不报，SmartScreen 直接信任 |

内部分发（同事/学校）可以不签名，附一句话说明即可；对外公开发布建议至少 OV。

### 2.2 API Key 怎么给

程序**没有内置任何 Key**（这是刻意的）。行为是：

- 没填 Key → 自动用**必应**免费翻译，开箱可用
- 想用大模型质量 → 用户在「设置 → 引擎」填自己的 DeepSeek Key（几块钱能翻很久）

> ⚠️ **绝对不要把自己的 Key 打进安装包发给别人**：Key 一旦泄漏会被人跑光余额，而且无法收回。

如果要"用户什么都不用配就有大模型质量"，正确做法是你在后端做一个转发服务（校验用户 → 转发到 DeepSeek → 限流），程序里填你的服务地址。这是一笔持续成本，量小不建议。

### 2.3 隐私与合规声明

翻译时**选中的文字会被发送到**：

- 必应（`www.bing.com`）——默认引擎
- DeepSeek（`api.deepseek.com`）——用户自己填 Key 时

程序本身不上传任何其它数据；历史/生词本只存本机 `%APPDATA%\InstaTranslate`。

如果发给学校或机构，建议在说明里写一句：**"选中的文字会发送到第三方翻译服务"**，避免有人拿它翻敏感材料。

## 3. 运行环境要求

- Windows 10 1809 及以上 / Windows 11（64 位）
- **.NET Framework 4.8**（Win10 1903+ 和 Win11 自带；Win7/8 需要装）
- 无需管理员权限、无需联网之外的特殊权限

程序启动时会自检：权限级别、取词链路、翻译引擎、语音、存储。用户双击 `自检.cmd` 就能看到。

---

## 4. 别人装完怎么用（可以直接抄给用户）

1. 双击安装包 → 开始安装
2. 若弹"Windows 已保护你的电脑"→ 点「更多信息」→「仍要运行」
3. 右下角托盘出现「译」图标（可能在 `^` 展开区里）
4. 任意软件里选中中文/英文 → 按 `Alt + C`
5. 想改快捷键 / 填自己的 API Key：托盘右键 → 设置

---

## 5. 已知限制（提前说明，省得被当 bug 报回来）

| 限制 | 说明 |
|---|---|
| 某些全屏游戏、DRM 窗口取不到词 | 这类窗口禁止读取选区，无解 |
| 以管理员运行的软件 | 普通权限读不到其选区，需以管理员运行本程序（托盘有入口） |
| 部分自绘界面（如某些游戏启动器） | 不支持 UIA 也不响应 Ctrl+C，取不到 |
| 企业内网被封 Bing/DeepSeek | 翻译会失败，需配代理或换内网引擎 |

---

## 6. 如果要做到更正式

按投入从低到高：

1. **加自动更新**：启动时查一个版本号文件，有新版本提示下载（约半天工作量）
2. **加使用统计**（可选、需告知）：知道有多少人在用、常用什么功能
3. **代码签名 + 官网/下载页**：对外发布的标配
4. **安装时可选"仅为当前用户/所有用户"**：目前固定当前用户（免 UAC），够用

---

## 7. 构建与自测命令

```bat
cd <项目目录>
node scripts\build-native.js      :: 编译程序 → dist\InstaTranslate 和 %USERPROFILE%\InstaTranslate
node scripts\build-installer.js   :: 打包安装程序 → dist\ + %USERPROFILE%\InstaTranslate
```

自测（每次改完都跑）：

```bat
InstaTranslate.exe --selftest     :: 权限/取词/引擎/语音/存储
InstaTranslate.exe --live-test    :: 自动开记事本→选中→取词→报结论
```

> 注意：如果工作区目录带"低完整性"标记（`icacls` 里出现 `Mandatory Label\Low Mandatory Level`），
> 从那里直接运行的程序会被降权、取不到词。构建脚本默认把可运行副本输出到 `%USERPROFILE%\InstaTranslate`，请从那里运行。
